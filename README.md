# Spotify Streaming Analysis

Spotify streaming data analysis and interactive dashboard using Power BI

![Spotify Dashboard](Spotify-Dashboard-Analysis.png)

##  Project Overview

This project analyzes Spotify streaming data to explore patterns in music consumption, artist performance, genres, countries, languages, and streaming types.

The project was created as part of my data analytics portfolio to practice data visualization, data exploration, and dashboard development.

##  Tools Used

* **Microsoft Excel** — Data cleaning and preparation
* **Power BI** — Data visualization and interactive dashboard

##  Analysis

The dashboard explores different aspects of the dataset, including:

* Total streams
* Top artists by streams
* Most streamed genres
* Streams by artist gender
* Streams by country
* Primary language
* Lead, feature, and solo streams

##  Dashboard

The dashboard was created in Power BI and includes interactive visualizations and filters that allow users to explore the data from different perspectives.

##  Key Insights

The analysis provides an overview of streaming patterns and highlights differences between artists, genres, countries, languages, and types of participation in songs.
